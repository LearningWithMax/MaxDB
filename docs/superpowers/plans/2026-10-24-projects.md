# Projects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Projects page (a shelf of five projects with status filters, a case view for this website, silent looping clips) and a three-tile Projects band on Home.

**Architecture:** Two new classic scripts: `js/projects.js` (the public data array, pure logic, HTML builders, thin DOM wiring) and `js/clips.js` (the video loop component). Routing grows one page and one sub-state. Clips are made by a dev-only stage page in `scripts/clips/` that animates real captures (cursor, click ripples, crossfades, slow zoom), records them in the browser with `MediaRecorder` and saves them through the dev server's existing guarded `/__save` route.

**Tech Stack:** Vanilla HTML/CSS/JS, Node 24 `node:test`, the browser pane (Chrome 152) for capture, recording and verification.

**Spec:** `docs/superpowers/specs/2026-10-24-projects-design.md` (approved 2026-10-24).

## Global Constraints

- No framework, no build step, no backend. Relative paths only, never a leading slash (the site lives under `/MaxDB/`).
- Classic scripts share one global scope; load order after this plan: data, vlog, popups, consent, route, lens, theme, clock, clips, projects, nav, map, home-intro. `check.mjs` parses them together, so every new top-level name must be unique across all scripts.
- Every color, font, spacing and width comes from `css/tokens.css`. No hex color in new CSS. The dark frame uses the existing fixed `--board`, `--board-edge`, `--board-ink`, `--board-mute`, `--board-gold` tokens. Shadows may reuse the `rgba(...)` values `home.css` already uses for `.preview-object`.
- Copy: no em or en dashes, American spelling, straight apostrophes. Site text may only use characters in `scripts/lib/font-text.mjs` (write arrows as `&rarr;` or `→`; there is no left arrow glyph).
- `js/projects.js` is public. It holds no private project and no client name; the words Chacao and Laboratorios, and any name listed in the git-ignored `scripts/private-names.local.txt`, must not appear in it or on the Projects page.
- Status keys `live`, `building`, `planned`; labels Live, Building and testing, Planned.
- Budgets: loop file 600,000 bytes; case loop 900,000; poster 60,000; media one page may fetch under 3,000,000; `node scripts/budget.mjs` pre-gate total under 150 KB gzip.
- No endless CSS animation (only `gateBreathe` and `hintBounce`); a video's `loop` attribute is not one. One gold star per screen: Home keeps it on the departures strip.
- Before every commit: `node --test scripts/*.test.mjs` all green and `node scripts/check.mjs` prints "All good." Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Work on branch `restructure`. Never push.
- Windows checkouts are CRLF locally, LF in git: prefer small targeted edits; use the Edit and Write tools for regex-heavy text, not shell heredocs.
- Pane facts: a hidden pane runs no animation frames (keep it in front, use real clicks and `computer wait`); `Image.decode()` stalls there, use `onload`; reset `resize_window` to `desktop` when done; screenshots are saved as JPEG files whose path the tool prints. Start servers with `preview_start` (`site` serves the repo; `save` is the same with the `/__save` route on). Stop them when done.

## Review Focus

1. **Reduced motion, data saver, or the opening still running:** the poster shows and no video file is requested. (Task 6 table test, pane network check.)
2. **Direct loads and Back:** loading `#projects/site` and `#projects/zzz` cold, and Back from the case view returning to the shelf. (Task 2 tests, Task 7 pane check.)
3. **A video that cannot play** (unsupported codec, missing file, `error` event): the poster stays, the tile still works, the console stays quiet. (Task 6.)
4. **JavaScript off or `projects.js` failing:** the noscript list names all five projects with status, the empty Home band disappears, the case text is readable. (Tasks 5 and 7 tests.)
5. **Filtering away the featured tile,** and tiles that open a new tab announcing it in their accessible name. (Task 4 tests.)
