# New Shell (Paper and Metal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the whole site the approved look (style B, paper and metal, dark first): tokens, self-hosted fonts, banner with clock and theme toggle, Home as preview cards, the CV restyled, the interim Trip page, the widgets, and the opening's new reveal.

**Architecture:** `css/tokens.css` is the only place colors, fonts, spacing and radii are defined; every other stylesheet reads tokens. `index.html` markup is rewritten page by page. Scripts stay classic; routes, lens, the opening controller, the board and globe modules, the checks and the tests are kept and extended. A temporary alias block maps the old variable names to the new tokens so each task can restyle one area at a time; Task 9 deletes it and a check proves nothing still uses it.

**Tech Stack:** HTML, CSS, vanilla JS, Node `node:test`, vendored woff2 fonts.

**Spec:** `docs/superpowers/specs/2026-10-21-art-direction-brief.md` (look, amended 2026-10-23 for the opening release) and `docs/superpowers/specs/2026-10-18-master-site-design.md` (pages, opening, content model). Branch `restructure`; nothing here is live.

## Decisions made in this plan (the owner can overrule any of them)

1. The banner shows `home / cv / trip` for now. `projects` (the nav word, the page and its Home preview) arrives with the Projects plan: no page exists yet and the spec forbids placeholder facts.
2. The route `map` becomes `trip` (`#map` redirects to `#trip`). The old flat map, restyled, is the interim Trip page until the Trip plan swaps in the globe.
3. The Home Trip preview uses a provisional still of the lab globe, replaced by the final render in the Trip plan.
4. Removed because nothing may loop on its own: the country marquee, the blinking visitor dot, the pulsing footer dot, the endless sticker wobble (it wobbles once on load). Kept: the gate's breathing and the story's scroll hint.
5. The visitor log moves into the footer, left side, as in the brief (today it floats over page text).
6. The board's lens colors follow the tokens: Chemistry `#3fcf8d`, Operations `#9aa3b0`, Customer-Facing `#ff7a4d` (the cream `All` color stays). The flip engine is not touched.
7. The "what I bring" three sentences are dropped; each lens row carries one line.
8. JetBrains Mono 400 only (no bold, `font-synthesis: none`), to keep the font budget.
9. Approving this plan approves these downloads in Task 1: font CSS from `fonts.googleapis.com`, woff2 files from `fonts.gstatic.com`, licence texts from `raw.githubusercontent.com/google/fonts` (Instrument Serif, JetBrains Mono, Inter).

## Global Constraints

- No build step. Classic scripts share one global scope; ES modules only for the opening, the board and the globe. Relative paths only (the site lives under `/MaxDB/`).
- Copy: no em or en dashes (characters or `&mdash;` / `&ndash;`), straight quotes, American spelling, company `Cann.Edenn`, lens `Customer-Facing`, Intelcia as one fact only, no phone number, nothing private in the repo.
- Colors (dark / paper): `--bg #15130f / #f2ece1`, `--panel #1c1a15 / #f8f3e9`, `--ink #f2ece1 / #16130e`, `--text-2 #cfc6b4 / #3d3829`, `--mute #968d7c / #6a6355`, `--rule #322e26 / #cdc3ae`, `--gold #d9ae4c / #a47a16`, `--gold-text #d9ae4c / #8a640f`, `--gunmetal #9aa3b0 / #4b5059`, `--teal #3fcf8d / #0d7040`, `--orange #ff7a4d / #b8431f`. The objects (board, strip, opening, gate) stay dark in both themes: `--board #101012`, `--space #07070b`. Text at least 4.5:1, lines and outlines at least 3:1 (measured: every pair passes; paper `--gold` is 3.32).
- Fonts: Instrument Serif (names, headings, lens words), JetBrains Mono (labels, nav, years, clock, captions; lowercase, 11 to 12px, tracking 0.03em), Inter 400 and 600 (body, `clamp(14px, 1.5vw, 18px)`, line 1.5 to 1.55), Roboto Condensed 700 (inside board objects, uppercase, tracking 0.18em). Self-hosted latin woff2, `font-display: swap`, 120 KB total at most, only Roboto Condensed 700 preloaded, no outside requests.
- Layout: content width 1140px, side padding 48px (18px under 700px), spacing 4, 8, 12, 16, 24, 32, 48, 72; corners: objects 12px, cards 6px, pills round; breakpoints 700px and 1000px.
- Motion: interface transitions 160 to 240 ms ease-out, page fade 200 ms, theme crossfade 250 ms; reduced motion makes every transition instant.
- Theme: dark on the first visit whatever the system says; `mdb-theme` holds `dark` or `light` (paper); `data-theme` is always set on `<html>`.
- Before the gate: HTML, CSS and classic JS at most 150 KB gzip (measured before this plan: 69.4 KB).
- Process: work on `restructure`, never push. After every task `node --test` passes and `node scripts/check.mjs` prints "All good.". Commit messages go in a file (`git commit -F`) and end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Check each visual change in the browser pane at 1280 and 375 wide, dark and paper.

## Review Focus

1. Theme storage: `mdb-theme` unreadable (blocked storage), a stray value (`purple`, `LIGHT`) or an old `dark` must give dark with no exception. Tested in Task 2.
2. The reveal is never cut: the finish timer firing before the last staggered fade ends, or a tab hidden mid-reveal, must land on the full page, never a half-faded one. Tested in Task 6.
3. At 375px nothing scrolls sideways: banner rows, departures rows, experience table, board tabs, footer. Checked with `document.documentElement.scrollWidth <= innerWidth` in Tasks 3, 5, 7 and 8.
4. JavaScript off or a failed module: hero, lens list, departures rows, CV and Trip text stay readable, and the page is dark by CSS default. Tested in Tasks 1, 4 and 5.
5. The clock shows Tel Aviv time for a visitor anywhere, across daylight saving, and hides itself rather than show a wrong time. Tested in Task 3.
