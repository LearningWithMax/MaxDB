# Trip Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put Fable's flight globe on the Trip page as a dark window object with eleven stops (born, study, work), a flat-map-and-list fallback, four album buttons, and a Home card image rendered from the real globe.

**Architecture:** The globe is Fable's finished module (`modules/globe.js`, `globe-data.js`, `jet.js`); this stage only mounts it. A new classic script `js/trip.js` owns the lifecycle (load on first visit, remove on leave, fall back on failure). The site's stop wording lives in its own file `modules/trip-stops.js`; a generated static list in `index.html` mirrors it for no-JavaScript and fallback visitors. Colors come from `tokens.css`.

**Tech Stack:** Vanilla HTML/CSS/JS, ES modules loaded on demand through the existing import map, Node 24 `node:test`, the browser pane for verification.

**Spec:** `docs/superpowers/specs/2026-10-24-trip-stage1-design.md` (approved 2026-10-24).

## Global Constraints

- No framework, no build step. Relative paths only. Classic scripts load in this order after this plan: data, vlog, popups, consent, route, lens, theme, clock, clips, projects, trip, nav, map, home-intro. New top-level names must be unique across all scripts.
- Do not edit `modules/globe.js`, `modules/globe-data.js` or `modules/jet.js`: Fable is still working on them (Explore mode). The one allowed edit outside the site files is stripping color fallbacks from `css/globe.css` (Task 2). If the site needs anything else from Fable's files, write it in the ledger and tell the owner.
- Every color, font, spacing and width comes from `css/tokens.css`. No hex color and no `rgb(a)` in `css/trip.css` or `css/globe.css`, except `rgba` in a `text-shadow` or `box-shadow`. The globe is a dark object in both themes, so its tokens are fixed values, not theme-dependent.
- Copy: no em or en dashes, American spelling, straight apostrophes, Cann.Edenn with two n, no "Technical Sales", Intelcia only by `INTELCIA_FACT` (`scripts/lib/rules.mjs`). HTML text uses entities as the existing file does (`&eacute;`, `&amp;`, `&middot;`).
- Before every commit run `node scripts/check.mjs 2>&1 | tail -1 | grep -q "All good"` AND `node --test scripts/*.test.mjs` with 0 failures, chained with `&&` so a failure stops the commit. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Work on `restructure`. Never push.
- Windows checkouts are CRLF locally and LF in git. Use the Edit and Write tools for regex-heavy text, not shell heredocs (they collapse backslashes). Compare generated HTML with whitespace between tags normalized.
- Pane facts: a pane that is not in front runs no animation frames: after `navigate`, call `tabs_select` and take one screenshot to wake it. The pane caches CSS and JS across edits: before checking a change, `fetch(path, { cache: 'reload' })` for each edited file, then reload. Reset `resize_window` to `desktop` when done; stop servers you start (`site` serves the repo, `save` adds the `/__save` route).

### Task 3: The lifecycle

**Files:**
- Create: `js/trip.js`, `scripts/trip.test.mjs`
- Modify: `js/nav.js`, `index.html` (the script tag only)

**Interfaces:**
- Produces in `js/trip.js` (classic script): `createTripLifecycle(deps) -> { mount(): Promise<void>, dispose(): void }` where `deps = { load(): Promise<{ mountGlobe, stops }>, host(): Element|null, setState(state: 'off'|'loading'|'on', message?: string), lite(): boolean, log(message): void }`; `mountTrip()` and `disposeTrip()` (globals, use the real deps); `tripLite()`.
- Behavior of `mount()`: while a mount is running or a controller exists, it returns the running promise and does nothing else. Otherwise it records that the visitor wants the globe, calls `setState('loading', 'Loading the globe')`, awaits `load()`, finds the host (a missing host is an error), then `mountGlobe(host, { stops, tailLogoUrl: 'img/logo/chrome-banner.webp', countriesUrl: 'vendor/data/countries-110m.json', lite: deps.lite() })`. If the visitor no longer wants it by then, the new controller is disposed and the state stays `off`. On success the state is `on`. On any error it calls `deps.log` once, leaves no controller and sets `off`. `dispose()` records that the visitor does not want it, disposes the controller if there is one and sets `off`.
- Real deps: `load` is `Promise.all([import('../modules/globe.js'), import('../modules/trip-stops.js')])` mapped to `{ mountGlobe, stops: TRIP_STOPS }`, and rejects with an Error when `location.hostname === 'localhost'` and the address has `failglobe` (the opening's `failopen` pattern). `host` is `document.getElementById('tripGlobe')`. `setState` sets `data-globe` on `#page-trip` and the text of `#tripMsg`. `lite` is `matchMedia('(max-width: 760px)').matches || (navigator.hardwareConcurrency || 8) <= 4`.
- `js/nav.js`: in `goTo`, after the board line, `if(page === 'trip' && window.mountTrip) mountTrip(); else if(window.disposeTrip) disposeTrip();`.
